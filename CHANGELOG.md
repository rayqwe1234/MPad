# Changelog

## 1.0.0 - 2026-08-30

- Added LAN companion mode with automatic discovery, pairing, XInput output, and phone rumble.
- Added Bluetooth companion fallback and Bluetooth HID direct mode.
- Added an editable Xbox-style touch layout with movable and resizable controls.
- Added shape-aware touch targets, continuous drag editing, and finger-following analog sticks.
- Added dark-mode support for Android and Windows.
- Added the Windows Companion and XInput controller tester.
- Added the local MPad product website.
