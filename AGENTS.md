# Project Instructions

## Development tools

- Install all development tools required by this project under `D:\DevTools`.
- Do not install project development tools on the C: drive unless the user explicitly approves an exception.
- When a tool supports a configurable install directory, cache directory, SDK directory, package store, or runtime directory, place the project-related files under `D:\DevTools` as well.
- Before installing a tool, verify its destination path and preserve any existing installations and data.
